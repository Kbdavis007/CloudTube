## Editor: "Add from your library" dropdown
- Added a dropdown of **saved videos with a direct media URL** (`playback.previewUrl`) that
  adds the chosen one as a clip via `readClipFromUrl`. New: `src/components/editor/LibraryClipPicker.tsx`,
  `readClipFromUrl` + `isEditableVideo` + `editableLibraryVideos` in `src/services/videoEditor.ts`,
  `EditorView` now takes a `videos` prop (passed from `src/App.tsx`).
- **Only RedGifs saved clips qualify.** Verified `https://media.redgifs.com/*.mp4` sends
  `access-control-allow-origin: <origin>` (reflects) and supports range requests, so a browser
  `fetch()` can read the bytes. Catalogue (Vega/Vortex) videos are iframe-only with no direct URL;
  YouTube likewise — so they are filtered out.
- Verification: 63 unit tests (added isEditableVideo/editableLibraryVideos/readClipFromUrl cases,
  fetch stubbed for the readable/non-media/blocked cases), 6 Playwright tests (added a dropdown
  test using a same-origin fixture as the "saved video"), tsc + vite build clean,
  `openspec validate --all --strict` passes.
