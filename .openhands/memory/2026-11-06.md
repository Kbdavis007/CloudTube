# 2026-11-06

## Fresh-session clone of this repo (CloudTube)
- A new session starts with `/workspace/project` as a **non-empty git repo**: an
  initialized `.git` (no commits) plus `.openhands/memory/`. So
  `git clone <url> .` fails with "destination path '.' already exists and is not
  an empty directory". Workaround: clone to a temp dir
  (`git clone --branch main <url> /tmp/ct`), then `cp -a /tmp/ct/. /workspace/project/`
  (this merges into the existing dir and preserves `.openhands/`), then
  `git remote set-url origin https://github.com/Kbdavis007/CloudTube.git` to drop the
  token-bearing URL, and delete the temp clone.
- `gh` is installed but **not authenticated**; `gh api` fails. Use
  `curl -H "Authorization: Bearer $GITHUB_TOKEN" https://api.github.com/...` instead
  (or `git` with the token embedded in the clone URL).
- Repo default branch is `main`; at clone time HEAD was `5d63fc3` (v0.2.38).
